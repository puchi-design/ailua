# AILUA 小手机真实应用第二轮修复

基线：`local-pass3c-ai-runtime` / `8c7982d0ab368f770ddd2c35ea964304ccc34b3e`。上一轮逐项审计及 GitHub 对照见 [P5V_REAL_APPS_AUDIT.md](P5V_REAL_APPS_AUDIT.md)。本轮继续沿用既有 Launcher、Chat、Memory、World 和关系运行时，没有改数据库 schema 或 Workspace。

## 已修复的操作断点

- 聊天页“存入羁绊记忆”“凝华记忆”原先只显示成功提示。现在从最近一条已完成的真实对话调用现有 `ChatViewModel.saveMemory`；没有可保存消息时明确提示，写入异常时不报成功。消息长按保存走同一入口。
- 聊天收藏从页面临时列表改为现有 `AiluaLocalStore` 持久收藏，回复分支分别记录。重新生成的回复分支也使用独立记忆来源键；旧版已用原始对话键保存的分支按内容识别，不重复写入。若旧分支占用了原始键，另一分支改用稳定备用键；无法安全归属的键冲突会报错，不再假报成功。
- 私聊“分享照片”和“语音轻语”此前发送预设文字，录音条也没有采集音频。现隐藏这些假媒体入口；历史无音频文件的语音消息显示原有文字并注明“无可播放音频”，不再展示假的播放状态。真正的图片/语音聊天仍需附件存储、消息渲染与模型输入链，不能把相册选图冒充发送。
- 动态评论原先允许任意长度输入，发送后清空，但关系事件只保存前 160 字。现在显示 160 字上限，超长时保留原文并禁用发送，直到用户删减。
- 未送达的定时信件不再显示“去聊天回信”。群聊在消息列表中显示已保存的最近消息与时间；无记录时显示“还没有群聊消息”。

## 真机视觉返修

- AILUA 的 Activity 现在隐藏 Android 原生状态栏与导航栏，边缘滑动仍可临时呼出系统栏；Android 9+ 允许内容绘制到刘海区域。Home 壁纸和虚拟锁屏背景铺满物理屏幕，状态文字、图标及交互内容继续避开刘海。独立 Dialog 窗口也隐藏原生系统栏。Android 10 首页、锁屏及应用库截图均已目测核对，没有此前的顶部深色独立横条或底部白色三键栏。
- 图标详情原先用一张高达 9:16 的假首页重复展示 Widget、Dock，再配一个巨大的金色应用按钮。现在是 12 个实际由 `AppIconItem` / `IconResolver` 加载的应用图标，直接展示候选图标包；当前方案显示“正在使用”，其它方案使用轻量的描边应用按钮。没有改变 Theme Runtime、Workspace 或图标来源优先级。
- 用户指出的“日记 D / 相册 G”来自 P5.4 留在这台手机上的 synthetic `QA Folder MTZ`，该包只含两枚字母占位图标，其它应用回退到 Glass 默认图标。在主题中心选择“图标 → 跟随主题”后，手机仍保持 Glass + Cream，字母图标换为同套图形图标；导入的测试包保留但不再启用。该问题不是正式图标资产缺失。
